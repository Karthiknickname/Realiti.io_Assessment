# Assessment

A simple task management app built with Next.js. It helps organize tasks across To Do, In Progress, and Done columns.

## Features

* Create, edit, and delete tasks
* Move tasks between columns using drag and drop
* Search and filter tasks
* Set task priority and due dates
* Save tasks in localStorage
* Responsive layout with smooth UI animations

## Tech Stack

* Next.js
* React
* JavaScript
* Tailwind CSS
* @dnd-kit
* Motion
* Lucide React

## Run Locally

```bash
git clone https://github.com/Karthickname/Realti.io_Assessment.git
cd Realti.io_Assessment
npm install
npm run dev
```

Open http://localhost:3000 to view the app.
